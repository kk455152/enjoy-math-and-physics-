## 每一步怎样交换

第 n 步动力学状态包括 `x_n, v_n, q_n, omega_n`；q 是球体姿态四元数。转盘状态为 `alpha_n, Omega_n`。电磁历史记为 `s_n`，包含磁场/电流离散自由度、磁化向量及模型所需的不可逆磁化状态。

```text
initialize(material,N,R,g,D, 初始位置/姿态/转盘相位, 初始磁化条件)
    -> 初始静磁基准、初始电磁状态 s0

advance(s_n, t_n, dt, 球与转盘在这一时间段的运动预测)
    -> F_total, T_total_about_ball_center, J, J_cross_B, B, H, s_trial

动力学利用 F_total、T_total 更新 x,v,q,omega
若该步接受：提交 s_trial
若动力学回退或重试：恢复 s_n，重算本时间段
```

速度应由动力学在每个时间步提供，不必等整条轨迹求完。仅给速度也不够：还需位置、姿态/自转、转盘相位及历史状态。变速时相位由角速度积分，不能用 `Omega(t)*t` 替代。

一次时间步可以采用预测—校正：动力学预测运动→电磁计算力→动力学校正运动→必要时重新计算电磁。即使先使用显式分步法，也要做时间步收敛；不能在自适应 ODE 的每次试探 RHS 中不可逆地修改同一个磁化历史对象。

## 可测试的逐步接口

`stepwise_em_model.py` 提供 `StepwiseElectromagneticModel.trial_step(state, memory)`。动力学每步给入试探时刻的位置、速度、转盘角度/角速度和球 z 自转；接口返回静磁力、低磁雷诺数涡流阻力估计、用逐高度 Jiles–Atherton 近似记忆估出的磁滞损耗力，以及候选新历史状态。调用不会修改输入历史；动力学接受这一步后才替换历史，回退/重试时丢弃候选状态。这实现了外层迭代的调用和回滚约定。

它仍是工程降阶模型，不是完整电磁解：从已验证的静磁中心线 B/H 估算空间梯度，只输出焦耳等效 RMS 电流密度标量，不输出局部向量 J 或体力密度 J×B。Jiles–Atherton 参数是根据骨干曲线、饱和磁化和矫顽力的工程估算；其历史状态目前只进入钉扎损耗力估计，没有反馈求解球内 B/H 和 Maxwell 应力。球自转只把 z 分量计入磁滞相对速率；自转涡流力矩、x/y 自转影响、完整三维球内场仍未解。因此不能把这个接口称作完整 COMSOL 任意轨迹瞬态解。

调用形状如下；相应工况的中心线场通过验证后才可运行：

```python
import sys
from pathlib import Path

sys.path.insert(0, str(Path("../连续磁力地图").resolve()))
from shared_parametric_map import SharedStaticForceMap
from stepwise_em_model import DynamicState, StepwiseElectromagneticModel

maps = SharedStaticForceMap()
em = StepwiseElectromagneticModel(maps, material="GCr15_hardened",
                                  N=4, R_mm=41, g_mm=3, D_mm=3)
s0 = DynamicState(t_s=0, x_mm=41, y_mm=0, vx_m_s=0, vy_m_s=0,
                  rotor_angle_rad=0, rotor_speed_rad_s=12)
memory = em.initialize(s0)
trial = DynamicState(t_s=1e-4, x_mm=41.02, y_mm=.01, vx_m_s=.2, vy_m_s=.1,
                     rotor_angle_rad=.0012, rotor_speed_rad_s=12)
force_row, candidate_memory = em.trial_step(trial, memory)
Fmag = force_row["Fmagnetic_xyz_N"]
# 用 Fmag 与动力学端的摩擦、接触力推进。只有接受这一步时才提交：
# memory = candidate_memory
```

静磁力图仍在后台计算；没有通过验证的场图会报错，不会借用邻近工况。

## COMSOL 原型依据

本机 COMSOL 6.4 ACDC 手册的 `Velocity (Lorentz Term)` 说明该节点添加 `J_ext=σ(v×B)`，并明确限制有限长度移动域和包含移动磁源的域；有限钢球不能直接照搬铜管落磁体例子的速度节点。Jiles–Atherton 则具有逐高斯点内部状态，手册说明其支持移动域。官方 `power_switch` 和 `axial_magnetic_bearing` 示例包含 Moving Mesh 的 `DeformingDomain`、`PrescribedDeformation` 和 `PrescribedMeshDisplacement`；`vector_hysteresis_modeling` 示范 JA 材料组和参数。

完整模型应采用 ALE 随体移动球域、旋转磁铁域和有历史状态的 JA 材料，再验证短时窗位移、网格收敛及状态传递。下述 H62 原型已通过短时窗求解，JA 移动磁性球分支仍未通过。审查文件在 `时变磁场模型/.build/motion_history_reference_20261029/`；手册章节为 `acdc_ug_magnetic_fields.08.040.html` 与 `acdc_ug_theory.05.15.html`。

## 2026-10-29 移动球短算例复核

`时变磁场模型/移动球磁滞原型` 的 H62 ALE 烟雾工况已补上 Stationary 初始步，并修正了 COMSOL 输出坐标的单位换算。`smoke_H62_stationary_init_v2` 在 `N=4, R=rho=41 mm, g=3 mm, D=3 mm, Omega=10 rad/s` 下对 0.1 mm 预设位移求解 3 个时刻；`t=0` 的焦耳损耗从错误零场初值算例的 `83.81 W` 降至 `2.82e-13 W`，之后运动时刻为 `9.21e-6 W`。这只确认 H62 的短轨迹 ALE 数值链路能运行，不能视为任意运动反馈闭环、局部随体场输出或收敛验证。

COMSOL 6.4 的 `RotatingMachineryMagnetic > PassiveConductor` 不允许将 GCr15 的 JA 本构直接挂接到该导电域；`smoke_solve_GCr15h_JA` 是失败尝试，不能用作物理结果。GCr15 的移动球磁滞仍需另行验证支持 JA 的物理接口；在此之前，静磁/可逆 B-H 与降阶磁滞记忆必须分开标记。

## 后续电磁实现必须满足

1. 在球体材料速度 `v_center + omega_ball × (r-x_center)` 下计算感应电流，处理移动网格/坐标系导数，避免漏算或重复加入运动感应项。
2. 转盘角度来自输入相位或时间积分；保持相邻磁极交替，支持变速、停转、反转。
3. 磁滞使用工程近似的有历史本构（例如参数受约束的 Jiles–Atherton），明确初始化、热处理和不确定性。单值 B–H 曲线不能唯一确定全部磁滞参数，不能把一个损耗公式当成已求解磁化历史。
4. 用包围球体的空气面 Maxwell 应力给总力/总矩，另导出球内 `J×B` 作分量诊断。**若已用瞬态 Maxwell 总力，就不能再叠加静磁合力与同一涡流力，避免重复计数。**
5. 整周连续推进电磁历史；球在两磁铁之间也不能重置磁化或把电流瞬间清零。当前静磁位置域已改为完整环带。
6. 批量覆盖材料/N/R/g/D 所有指定组合；速度和任意轨迹是在线输入，不可能预先穷举所有连续运动历史。
7. 用零运动、反向运动、同位置不同磁化历史、重启连续性、时间步和网格收敛、能量收支检查验收。对 H62，零运动且无初始电流时静磁力应为零；对有磁性球，完整模型的静止初态应与匹配的可逆/磁滞初态参考一致。
