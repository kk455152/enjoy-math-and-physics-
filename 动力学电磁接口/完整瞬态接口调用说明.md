# 完整瞬态电磁反馈接口

本接口使用 `时变磁场模型/通用瞬态耦合/FullTransientCarousel.java` 中的三维 COMSOL 磁场方程、移动网格和矢量 Jiles–Atherton 本构。动力学提供运动历史；电磁计算返回总力、总力矩、球内场和试算历史。

**计算成功、接口逻辑通过测试、数值精度通过收敛验证是三件不同的事。** 当前返回记录中的 `numerically_validated` 保持为 `False`，最新原生求解情况以各结果目录中的 `run_status.json` 和验证报告为准。

2026-10-30 用户确认继续保留完整磁滞。正式调用使用 `magnetization_model="jiles_atherton"`，这也是后端默认值；`reversible_bh` 仅作为可选对照和故障定位分支，不代表已经证明磁滞对速度可忽略。关闭磁滞的对照仍保留饱和与瞬态涡流历史。

## 一个共有的调用关系

\[
(\mathbf F,\boldsymbol\tau,\mathbf B,\mathbf H,\mathbf J,\mathbf M,S_{n+1}^{\rm trial})
=\mathcal E(p,S_n,\text{motion}_{n\to n+1}).
\]

参数 \(p\) 包括材质、磁环布局、球直径 \(D\)、间距 \(g\) 和材料本构参数。\(S_n\) 包含电磁场、空间磁化历史以及已接受运动历史。**不能用一个没有历史状态的 \(F(x,v)\) 代替完整的涡流和磁滞模型。** 相同位置、速度可能对应不同磁化历史。

两组布局和四个材料分支共用同一份求解器代码：

| 输入 | 当前范围或定义 |
|---|---|
| `material` | `H62`、`PC40`、`GCr15_hardened`、`GCr15_annealed` |
| `N, R_mm` | `(4,41)` 或 `(10,96)`；R 为磁铁径向中心半径 |
| `D_mm` | 连续变量，3–10 mm，**直径** |
| `g_mm` | 连续变量，3–6 mm，磁铁顶面到平板底面的距离 |
| 球心位置 | 整圈位置均可输入；\(R-15\leq\sqrt{x^2+y^2}\leq R+15\) mm |
| 平板 | 当前假设厚 1 mm、不导电、不导磁；球保持与板接触 |
| 磁铁 | 径向 30 mm，切向 10 mm，厚 3 mm，Br=1.42 T；交替轴向极性 |
| 转盘运动 | 输入展开的绝对角度和角速度；允许变速、停止、反向 |
| 球自转 | 输入实验室坐标系下的三个角速度分量 |

“正上方范围”限制的是运动半径带，不把瞬时切向坐标限制在 ±5 mm。不要在两种磁环布局或不同材料之间直接插值。

## 最小调用

在 `动力学电磁接口` 目录运行 Python，或将该目录加入你程序的模块搜索路径。COMSOL 默认位置为 `D:/Program Files/COMSOL/COMSOL64/Multiphysics/bin/win64`。

```python
from full_transient_stepper import ComsolTransientStepper
from stepwise_em_model import DynamicState

# D_mm、g_mm、material、N、R_mm 由你的工况参数提供。
settings = dict(
    material=material, N=N, R_mm=R_mm, D_mm=D_mm, g_mm=g_mm,
    rho_mm=R_mm, delta_deg=0, Omega_rad_s=0,
    dt_s=em_max_step_s, Rair_mm=180, mesh_scale=1.5,
    rtol=1e-3, threads=2,
    initialization_mode="bh_equilibrated",
    magnetization_model="jiles_atherton",
)
em = ComsolTransientStepper(settings, "电磁瞬态运行结果")

# state0、state1 都由动力学程序构造；位置单位 mm，速度单位 m/s。
# DynamicState(t_s, x_mm, y_mm, vx_m_s, vy_m_s,
#              rotor_angle_rad, rotor_speed_rad_s,
#              omega_ball_z_rad_s=0,
#              omega_ball_x_rad_s=0, omega_ball_y_rad_s=0)
initial_record, memory = em.initialize(state0)
record, trial_memory = em.trial_step(state1, memory)
F = record["Fmagnetic_xyz_N"]
T = record["Tmagnetic_xyz_Nm"]

# 只在动力学接受该时间步后执行：
memory = trial_memory
# 若拒绝、减小 dt 或修正轨迹，继续使用原 memory 重新试算。
```

`rho_mm` 和 `delta_deg` 在初始化时由真实球心位置、转盘相位重新计算；它们不是拟合实验速度的参数。`Omega_rad_s` 是原生三列轨迹格式的后备输入；逐步调用以 `DynamicState` 中的转盘角度和角速度为准。

端点之间，球心位置及转盘角度采用端点位置/速度的三次 Hermite 轨迹，并加密为原生运动输入。球自转采用实验室角速度的中点积分构造单位四元数。运动离散与电磁时间步均需要收敛检验；端点信息不能恢复未提供的真实中间运动。

## 与动力学相互迭代

`full_coupling_driver.py` 提供 `predictor_corrector_full_step`，同时迭代磁力与磁力矩：

```python
from full_coupling_driver import predictor_corrector_full_step

# 你实现的 dynamics_trial(state,Fxyz,Txyz,dt)
# 从同一个起点试算，返回该时间步终点的 DynamicState。
step = predictor_corrector_full_step(
    em, state, memory, dynamics_trial, dt,
    previous_force_xyz_N=previous_F,
    previous_torque_xyz_Nm=previous_T,
)
state = step.state
memory = step.candidate_memory  # 接受后提交
```

迭代失败会抛出 `FullCouplingConvergenceError`；保留原状态与原 memory，减小时间步再试。不要把试算函数写成会原地修改已接受动力学状态的函数。

## 求解内容与输出

导体中使用移动介质的磁准静态关系：

\[
\nabla\times\mathbf H=\mathbf J,\quad
\nabla\cdot\mathbf B=0,\quad
\nabla\times\mathbf E=-\partial_t\mathbf B,\quad
\mathbf J=\sigma(\mathbf E+\mathbf u\times\mathbf B).
\]

球内速度为球心平移与刚体自转速度之和。磁性材料满足 \(\mathbf B=\mu_0(\mathbf H+\mathbf M)\)，\(\mathbf M\) 由 COMSOL 矢量 JA 本构及空间历史状态计算。H62 使用 \(\mu_r=1\) 的导电分支。

磁性球的总力与总力矩来自 Maxwell 应力积分。球外空气中的应力为

\[
\mathbf T=\mu_0^{-1}(\mathbf B\otimes\mathbf B-\tfrac12 B^2\mathbf I),\quad
\mathbf F=\oint\mathbf T\mathbf n\,dS,\quad
\boldsymbol\tau=\oint(\mathbf r-\mathbf r_c)\times(\mathbf T\mathbf n)\,dS.
\]

H62 分支采用 \(\mu_r=1,M=0\)，其全部磁力可直接用 \(\int\mathbf J\times\mathbf B\,dV\) 及相应力矩计算。该分支以此返回总磁力，同时保存原始表面 Maxwell 积分作网格误差诊断，避免把表面积分的离散偏置解释为铜球静磁吸力。

磁性球的 `JxB_integral_xyz_N` 是自由电流洛伦兹力的诊断积分；**不要再把它或静磁力地图加到 `Fmagnetic_xyz_N` 上**，否则重复计力。磁滞对磁力的影响已经通过本构改变空间场；不能另外凭一个固定阻力项唯一拆分。

| 文件/返回项 | 内容 |
|---|---|
| `total_force_history.txt` | 总力、总力矩、J×B 积分及力矩、焦耳功率、Jrms、平均磁化、网格体积变化 |
| `ball_fields_last.csv` | 末时刻球内三维网格上的 B、H、J、M、J×B；包含整个球体各高度 |
| `TransientCarousel_<material>_solved.mph` | 原生网格、解与 JA 内部状态 |
| `coupling_memory.json` | 可恢复的已接受/试算机械历史、来源哈希和原生结果路径 |
| `motion_history.json` | 实际输入的完整运动序列，便于追溯 |
| `run_status.json` | 求解状态、来源版本、是否已数值验证 |

恢复已保存的历史：`memory = em.load_memory("某次运行/coupling_memory.json")`。该文件是这次运行的候选历史，**文件存在不代表动力学已经接受这一步**；动力学应另外保存自己已接受的历史文件路径，重启时按该路径恢复，不要直接挑最新结果目录。更改材料、几何、求解设置或求解器源码后，需要重新初始化。

## 初态、精度与性能边界

默认 `bh_equilibrated` 先在同一网格上求可逆 B–H 静态初场，将 \(M_0=B_0/\mu_0-H_0\) 映射到 JA 初始状态，再进行瞬态计算。这是假设的初始平衡磁化，**不等于测得了真实磁化历史，也不等于完整的预磁化实验**。若已知初始均匀磁化，可使用 `initialization_mode="uniform_M"` 并提供 `M0x_A_m/M0y_A_m/M0z_A_m`；零向量仅代表所指定的零磁化初态。

JA 的 Ms、a、k、c、alpha 使用工程估计。单条 B–H 曲线不能唯一确定磁滞回线参数，因此材料分支的定量误差仍需实测回线或相关实验约束。PC40 采用很低的有限电导率，不能据此宣称绝对零涡流。

`bh_curve_source="supplied_table"` 为默认初场曲线来源。诊断可选 `"ja_anhysteretic"`，由相同 JA 的 Ms、a、alpha 生成可逆骨干曲线，保持饱和；这不会关闭主模型的 JA 不可逆状态。两种来源是不同的初态/材料近似，切换后应重新初始化，不要混用历史。对照工具为 `通用瞬态耦合/compare_transient_runs.py`，它检查同一源码、相同运动和其余工况参数，并比较总力、总力矩与冲量；这些差异本身不能决定耦合速度误差。

当前参考实现对每个试算**从同一个初态重放全部已接受历史**，不会每步重置电流和磁化。它保证历史输入与试算提交的逻辑一致，但计算昂贵；尚未把 `.mph` 的直接断点续算作为经过验证的加速方法。

连续网格会随球移动、自转和转盘旋转而变形。短轨迹成功不能证明长距离、多周运动同样可用；大运动需自动重网格及磁化状态映射验证。`automatic_remesh="true"` 是实验选项，默认关闭，当前强制重网格测试尚未通过，不应作为已验证功能使用。求解失败或出现负网格体积时，接口不会返回可用于动力学的成功记录。只有完成时间步、网格、外边界和运动离散收敛，以及零运动/往返磁化/能量等检查，才能把某一范围标记为数值可靠。
