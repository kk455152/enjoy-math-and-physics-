# 逐步动力学耦合接口

> 2026-10-30：静磁数据已改为八组共有四维参数插值。新项目应传入 `shared_parametric_map.SharedStaticForceMap()`，支持 `g∈[3,6] mm`、`D∈[3,10] mm` 的连续输入；只在新清单通过验证后开放数值查询。下方旧 `StaticForceMap` 示例保留作方法记录。自适应检查还在运行，新状态见 `连续磁力地图/统一参数模型/manifest.json`。这没有改变下述降阶瞬态限制。

`coupling_driver.py` 将动力学的一步积分器和电磁 `trial_step` 按同一时间步进行预测—校正。动力学端每步提供当前运动状态和外力模型，返回下一时刻的球心位置、速度、自转以及转盘相位/角速度；电磁端根据该候选状态返回磁力和候选磁化记忆。只有力迭代收敛后，调用方才把候选位置和候选记忆作为已接受状态。

```python
from coupling_driver import predictor_corrector_step
from stepwise_em_model import DynamicState, StepwiseElectromagneticModel
from shared_parametric_map import SharedStaticForceMap

em = StepwiseElectromagneticModel(
    SharedStaticForceMap(), material="GCr15_hardened", N=4,
    R_mm=41, g_mm=3, D_mm=3,
)
state = DynamicState(
    t_s=0.0, x_mm=41.0, y_mm=0.0, vx_m_s=0.0, vy_m_s=0.0,
    rotor_angle_rad=0.0, rotor_speed_rad_s=12.0,
)
memory = em.initialize(state)
previous_force = (0.0, 0.0, 0.0)

def dynamics_trial(s, magnetic_force_xyz_N, dt_s):
    # Replace this body with the dynamics student's integrator. Include
    # friction, gravity, contact forces, ball spin and rotor phase there.
    return dynamics_integrator(s, magnetic_force_xyz_N, dt_s)

step = predictor_corrector_step(
    em, state, memory, dynamics_trial, dt_s=1e-5,
    previous_force_xyz_N=previous_force,
)

# Commit only after the dynamics solver accepts this step.
state = step.state
memory = step.candidate_memory
previous_force = tuple(step.force_record["Fmagnetic_xyz_N"])
```

若 `CouplingConvergenceError`，应从原来的 `state` 和 `memory` 缩小时间步重试；失败试算没有推进输入磁化状态。自适应积分器每次评估右端项时也必须从已接受的记忆副本试算，不能在试探调用中就地更新历史。

目前可接的 `StepwiseElectromagneticModel` 是静磁地图加低磁雷诺数涡流近似和工程 Jiles–Atherton 损耗记忆。它会返回总近似磁力，但没有求解局部向量 `J`、体力密度 `J×B`、自转涡流力矩，Jiles–Atherton 记忆也没有反馈到空间磁场解。现有 COMSOL 时变模型可输出固定球体条件下的真实 `J`、`J×B` 和积分涡流力，尚未跟随输入的移动球轨迹。因而这个驱动器实现了逐步交换、力校正和记忆回滚的程序框架，不能据此称为任意运动球的完整电磁闭环。

连续磁力地图的插值切片尚在计算时，`StaticForceMap` 会拒绝查询未验证切片。请先检查 `../连续磁力地图/manifest.json` 中对应切片的 `continuous_query_ready`；当前 campaign 未完成，不能用未完成切片驱动结果。
